DLSSG Manager 1.0.0 — 使用说明
================================================================
为 NVIDIA RTX 20 / 30 系显卡解锁 DLSS 帧生成（DLSS-G）
底层为开源项目 DLSSG Native 0.2.4：https://github.com/sdli1995/dlssg_for_sm86


一、这是什么
----------------------------------------------------------------
官方 DLSS 帧生成只给 RTX 40 系（Ada）。本工具的底层 Mod 用自研包装层 +
SM86/SM75 内核，以系统 DLL 代理的方式接入游戏的 D3D12 渲染进程，让
RTX 30 系（Ampere, SM86）和 RTX 20 系（Turing, SM75）也能开启 2X/3X/4X 插帧。

本程序是它的图形化外壳，做三件事：
  1. 自动识别本机已安装的游戏（Steam / Epic / GOG / Ubisoft / 免安装目录 / 深度全盘反查）
  2. 一键启用：自动挑可用入口、写入配置、部署前备份
  3. 一键恢复：删掉本工具写入的文件，还原备份


二、目录结构（不要拆散）
----------------------------------------------------------------
  DLSSG Manager.exe      主程序，双击运行
  payload\               运行包，必须和 exe 放在一起
    version.dll            默认代理入口（内含全部推理资源）
    altnative\winmm.dll    备用入口（当 version.dll 被别的 Mod 占用时用）
    altnative\dinput8.dll  备用入口
    altnative\winhttp.dll  备用入口
    altnative\dxgi.dll     备用入口
  icon.ico               图标
  使用说明.txt           本文件

注意：payload 文件夹缺失时程序会在日志里报错并拒绝部署。


三、怎么用（三步）
----------------------------------------------------------------
1. 双击 DLSSG Manager.exe。先出现 KANNI 载入动画（字符逐个渐显、循环呼吸），
   动画期间程序在后台做显卡探测与运行包校验；准备完成即自动淡出进入主界面，
   随后自动扫描并列出本机游戏。
   非平台安装的游戏没被识别到，就点：
     · “深度扫描” → 选盘符（按 DLSS 运行库反查，能挖出免安装游戏）
     · “手动添加游戏目录…” → 选游戏目录（若选的是库目录，会把子目录当游戏；
       若选的就是游戏目录，则整个按一个游戏处理）

2. 在左侧点选游戏，右侧确认三件事：
     · 渲染进程：必须指向真正跑画面的那个 exe（Unreal 游戏通常是
       …\Binaries\Win64\xxx-Win64-Shipping.exe）
     · 支持帧生成：显示“支持帧生成”才值得开；显示未检测到也能试，但多半无效
     · 反作弊：识别到反作弊的游戏，请只在单机 / 离线模式使用

3. 选好倍率后点“一键启用插帧”，然后完全重启游戏，
   在画面设置里打开“帧生成”并选择 2X / 3X / 4X。


三·五、系统准备：硬件加速 GPU 计划（HAGS）
----------------------------------------------------------------
本功能建议开启“硬件加速 GPU 计划”，否则帧时间可能不够稳。软件左侧
“系统准备”卡片会自动检测，你不需要自己去翻系统设置。

  卡片右上角胶囊会直接显示状态：
    已开启    一切就绪，不用管
    未开启    建议点“一键开启”（自动写入注册表，需管理员权限）
    不可用    系统版本过低（需 Win10 2004+ / build 19041 及以上）
    需管理员权限  当前不是管理员运行，用“手动设置”自己切换

  两个按钮：
    一键开启    自动写入 HwSchMode 到注册表。改完必须重启电脑才生效。
                开启后按钮变成“关闭”，可随时改回去。
    手动设置    直接打开 Windows 的“设置 → 系统 → 屏幕 → 图形设置”页面，
                自己手动拨那个开关。

  手动操作的路径（如果不想用软件改）：
    Windows 10：设置 → 系统 → 显示 → 图形设置 → 硬件加速 GPU 计划 → 开
    Windows 11：设置 → 系统 → 屏幕 → 图形设置 → 硬件加速 GPU 计划 → 开

  说明几点：
    · 开启 HAGS 对插帧有正向作用——让 GPU 自己调度命令队列，插帧这种额外
      提交量下能减少 CPU 侧调度开销与帧时间抖动。不开也能用，只是稳定性差些。
    · 改完注册表要重启电脑，不是重启游戏。
    · 一键开启写的是策略级值，系统的图形设置页面里那个开关会变灰锁定，
      这是正常的。想恢复成可自由切换，用本软件再点一次“关闭”。
    · 部署游戏时，如果 HAGS 没开，日志里会自动出现一条 [提示] 提醒你。


四、配置项说明
----------------------------------------------------------------
  显卡路由   自动（推荐）跟随检测到的显卡；RTX 30 系 = SM86，RTX 20 系 = SM75
             KernelImage 固定为 PTX（由驱动 JIT，兼容性最好）
  入口 DLL   自动选择：按 version → winmm → dinput8 → winhttp → dxgi 顺序，
             跳过已被其他程序占用的名字，绝不覆盖别人的文件
  插帧倍率   2X / 3X / 4X，对应 MaxGeneratedFrames = 1 / 2 / 3
  采样模式   精确（默认，输出与官方一致）/ 近似（仅 SM86，可能更快，生成像素会变）
  诊断日志   打开后 Level=2，日志写在游戏 exe 旁的 dlssg_sm86\logs


五、显存要留够（很容易被忽略）
----------------------------------------------------------------
开启插帧后额外占用（按“最终输出分辨率”算，不是渲染分辨率）：

  输出 1080p   2X 约 320 MiB   3X 约 330 MiB   4X 约 340 MiB
  输出 1440p   2X 约 490 MiB   3X 约 510 MiB   4X 约 520 MiB
  输出 4K      2X 约 700 MiB   3X 约 740 MiB   4X 约 770 MiB

显存不足或超过 Windows 分配的显存预算时，会出现偶发卡顿、帧时间尖峰，
即使平均帧率看起来正常。程序会根据识别到的游戏分辨率实时给出估算。


六、恢复与卸载
----------------------------------------------------------------
点“一键恢复”即可：删除本工具写入的代理 DLL 和 dlssg_sm86.ini，
并把部署时备份的同名文件还原回去。游戏自带的 DLSSG 文件不会被碰。

手工卸载也一样：删掉游戏目录里那个代理 DLL 和 dlssg_sm86.ini 即可。

部署记录与备份在这里（删掉即彻底清空本工具痕迹）：
  %LOCALAPPDATA%\DLSSGManager\state.json
  %LOCALAPPDATA%\DLSSGManager\backups\<游戏哈希>\


七、常见问题
----------------------------------------------------------------
· 进游戏没反应 / 没出现帧生成选项
  把“诊断日志”打开再部署一次，重启游戏后看 exe 旁 dlssg_sm86\logs。
  完全没有日志 = 目录选错了，或这个 DLL 名没被游戏加载，换一个入口 DLL。

· 提示“五种入口名均已被其他程序占用”
  说明游戏目录里 version/winmm/dinput8/winhttp/dxgi 五个名字都被占了。
  先用“入口 DLL”下拉框手动指定其中一个（会先备份原文件再覆盖）。

· 提示游戏正在运行
  完全退出游戏（含后台进程）再操作，文件被占用时无法写入。

· 杀软 / SmartScreen 报警
  DLL 代理 + LoadLibrary hook 属于这类接入的常见误报。程序内置 SHA256 校验，
  每次部署都会核对：version.dll = c844646d835a7b88ed1382eea80403d38b433f8ac09cf92581c73698c44ae7c2
  不放心可对照 ZIP 旁的 .sha256 或文件属性里的数字签名（项目自签证书）。

· 和别的 Mod 冲突
  本工具只占用一个代理 DLL 名，且优先选没被占用的名字。若某游戏已装
  ReShade 之类占用 dxgi.dll 的 Mod，本工具会自动避开。

· 卡片显示“不可用”
  硬件加速 GPU 计划需要 Windows 10 2004（build 19041）及以上 + 较新的
  NVIDIA 驱动。达不到就维持原样用即可，不影响插帧本身。

· 点“一键开启”提示需要管理员权限
  右键 DLSSG Manager.exe → 以管理员身份运行；或点“手动设置”自己切换。


八、界面与交互
----------------------------------------------------------------
· 启动载入动画：KANNI 字样逐字符渐显并循环呼吸，动画期间后台完成显卡探测
  与运行包校验；准备就绪后自动淡出进入主界面（最少停留 2.6s，最长 4.2s）。
  载入动画是独立窗口，会严丝合缝地跟随主窗口移动 / 缩放，不会出现错位或卡住。
· 窗口按钮：左上角为 macOS 风格三色圆点——
    红 = 关闭   黄 = 最小化   绿 = 最大化（再点还原，拖动标题栏也会还原）
  鼠标悬停时圆点内会显示对应的 ✕ / − / ⤢ 符号。
· 标题栏右侧有一个 HAGS 状态胶囊，和左侧「系统准备」卡片同步，一眼可看。
· 双击标题栏 = 最大化 / 还原；窗口四边与四角均可拖动缩放。
· 程序图标：深空蓝底 + KANNI 的「K」字标 + 一道插帧弧，上下两条胶片齿孔呼应
  「帧生成」。图标内嵌 16/24/32/48/64/128/256 共 7 个尺寸，
  任务栏、Alt+Tab、资源管理器里都清晰。

八·五、多语言（I18N）
----------------------------------------------------------------
· 内置语言：简体中文（默认）、繁體中文、English。
· 首次启动自动跟随系统语言；之后记住你的选择。
· 切换：标题栏右上角的语言下拉框（选项以各语言原生名字显示），
  选好后重启程序即整窗生效。
· 也可用命令行临时指定：DLSSG Manager.exe --lang en_US（或 zh_TW / zh_CN）。
· 添加新语言：在程序目录新建 lang\<语言代码>.json（UTF-8），
  格式见自带 lang\en_US.json —— 键为简体中文原文，值为译文，另加
  "_meta": {"name": "语言原生名"}。重启程序即可在下拉框看到，无需重新打包。
· 译文中 {0} {1} 这类占位符请原样保留；[错误]/[警告]/[完成] 等方括号前缀
  决定日志颜色，请一并保留。


九、能力边界
----------------------------------------------------------------
· 仅 Windows x64 + D3D12 游戏；Vulkan 尚未支持（上游计划中）
· 需要 NVIDIA 驱动提供 NGX/NVAPI 接口，无需安装 CUDA Toolkit 或 Python
· 最高生成 3 帧；不支持 6X / 动态倍率 / Reflex Warp / Reflex 自动矩阵查询
· 上游实卡验证为 RTX 3080 Ti；RTX 20 系（物理 Turing）仍待上游验证
· 反作弊严格的线上游戏请勿使用，本工具仅供单机 / 离线 / 实验室环境
· 本程序不做任何联网行为，全部操作都在本机完成
