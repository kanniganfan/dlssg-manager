# DLSSG Manager v1.9.1

- Right-click a scanned game to ignore it from future scan results. Game files, settings, and deployment files are preserved; deployed entries must be restored before they can be removed.
- Added a Restore Removed button for bringing ignored games back into scan results.
- Added per-option explanations for DLSS-G presets A/B/C and Super Resolution Off, M/L INT8, and M/L FP16.
