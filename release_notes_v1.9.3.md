# DLSSG Manager v1.9.3

- Anti-cheat detection is informational only: no button is disabled, no deployment is blocked, and no online/offline restriction is imposed. The hint now states explicitly that it does not affect deployment and leaves the choice to you.
- Removed the "single-player / offline only" wording from the footer and the deployment hint.
- New "Scale" selector in the title bar: 100% / 110% / 125% / 150%, persisted in state and applied on the next launch via a single global scale factor, so fonts, paddings and icons stay in proportion.
- Default window size is now 1280×900, clamped to the usable screen area and centered, so the footer never lands below the taskbar on smaller or scaled displays.
